.. py:class:: FingerprintOptions()

   ::

      Configuration for fingerprint-based comparison.

      Fields are grouped by the axis they control. Per-family fields are read only
      when the matching ``fp_type`` is selected, and per-metric fields only when the
      matching ``metric`` is selected; an unused field is ignored rather than
      rejected, so a default-constructed struct is a working Morgan configuration.
      The Python layer is stricter, because it can see which arguments the caller
      actually named.

.. py:class:: SparseStorage(n, cutoff)

   ::

      Sparse storage backend that stores only distances at or below a cutoff.

      Every value ``Set`` writes at or below the cutoff is kept, 0.0 included, and
      a pair written twice keeps both values. NaN, which compares above no cutoff,
      is kept too; a value above the cutoff, such as +inf under a finite cutoff, is
      discarded. Efficient for large, sparse distance graphs where most pairwise
      distances exceed the cutoff.
